# Flyverbox

1. Læg MP3-filerne i mappen `tracks/`.
2. Åbn `index.html` og udfyld listen `TRACKS`, fx:
   `{ title: "Jingle Bells", artist: "Navn", src: "tracks/jingle-bells.mp3" }`
3. Opret et offentligt repo på GitHub, upload alt, og slå GitHub Pages til (Settings > Pages > Branch: main).
4. Åbn adressen i Chrome (eller Chrome på Android) og tryk på Cast-knappen.
